# captionsai-site

Public pages for the CaptionsAI iOS app, served by GitHub Pages:

- `/privacy/`: the privacy policy. Generated from `PRIVACY.md` in the app
  repository, which is the source of truth (the app also bundles it). Do not
  edit `privacy.md` here by hand; re-run `scripts/publish-site.sh` in the app
  repository.
- `/support/`: support and contact.

Site: https://lalit-khatri.github.io/captionsai-site/
